the twelve brand animations are 256 x 256 pixels, 80 frames, 50ms per frame,
and loop indefinitely every four seconds. the twelve action badges are
128 x 128 pixels, 48 frames, 50ms per frame, and loop every 2.4 seconds.
all action pictograms are original vector drawings. the discord image assets
contain no text: only the brand logos, motion, and separate action pictograms.
action badges stay bold enough for a 32px thumbnail. action wording belongs
in the discord text fields, not inside the images.
png files are static fallbacks.
all discord image backgrounds are fully opaque pure black, including corners.
a faint 1.2px edge glow is confined to the brand logo silhouettes. orbit lines
and action pictograms have no blur, ambient gradients, or colored backdrop fills.
each animated file uses a single palette across the whole loop to avoid color
flicker, with exact black reserved for untouched background pixels.
gif assets need public https hosting for discord; local file paths do not work in rich presence.
the preview includes a pause control and honors the system reduced-motion preference.
