asset credits

everything in this folder is original pixel art drawn in code for this project
(scripts/pixel-art.cjs and scripts/action-art.cjs). no official image files are
copied or traced. the characters are fan redraws of each product's own mascot
where it has one:

claude: clawd, the claude code mascot, redrawn from the terminal welcome art.
https://github.com/anthropics/claude-code

codex: the default pet from the codex app (a cloud head with a terminal face).
https://github.com/openai/codex

deepseek: its whale logo, drawn as a little whale.
https://www.deepseek.com/

opencode: no mascot, so its block "o" logo mark.
https://opencode.ai/brand

glm / z.ai: no mascot, so the z.ai "z" tile.
https://z.ai/

brand, character and trademark rights remain with their owners.
this is an independent fan project, not affiliated with or endorsed by
openai, anthropic, opencode (anomaly), deepseek, or zhipu ai / z.ai.
if an owner wants a character removed, open an issue.

regenerate
  npm ci
  npm run assets

the big images (one per character and state, plus codex and claude together)
are 256 x 256 pixels, 16 frames, 120ms per frame, a loop just under two seconds.
the twelve action badges are 128 x 128 pixels with the same timing. discord crops badges to a circle, so each icon stays in
the middle of its tile. there is no text inside the images. action wording
belongs in the discord text fields.
png files are stills for when animation is off.
every gif uses one exact palette for the whole loop, so colors never flicker.
gif assets need public https hosting for discord; local file paths do not work in rich presence.
the preview page has a pause button and honors the system reduced-motion preference.
